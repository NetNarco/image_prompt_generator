❓ Краткая инструкция по Groq Cloud API

  1. Регистрация: Перейдите на сайт https://console.groq.com и нажмите "Sign Up" (или войдите через Google/GitHub). Создайте аккаунт бесплатно, без кредитной карты. Новые пользователи получают доступ к free tier сразу после регистрации.
  2. Получение бесплатного API-ключа: После входа перейдите в раздел "API Keys" (https://console.groq.com/keys). Нажмите "Create API Key", укажите имя (опционально) и сгенерируйте ключ. Он бесплатный и готов к использованию. КЛЮЧ СКОПИРУЙТЕ И СОХРАНИТЕ. ПРОСМОТРЕТЬ ЕГО ПОТОМ БУДЕТ НЕЛЬЗЯ.
  3. Выбор и получение бесплатной модели: Перейдите в playground (https://console.groq.com/playground) или документацию моделей (https://console.groq.com/docs/models), где перечислены бесплатные варианты (например, Llama 3.1, Mixtral, Gemma, Whisper). Выберите модель и интегрируйте её в API-запросы с вашим ключом (документация). Учтите лимиты free tier: например, для Llama-3.1-405b — 131 072 токенов в минуту/день; для других моделей лимиты ниже (проверьте в аккаунте). Developer tier предлагает до 10x выше лимиты за плату.
