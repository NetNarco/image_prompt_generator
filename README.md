# IPG Prompt Generator

Веб-приложение для создания и улучшения AI-промптов с поддержкой стилей, настроек качества, художественных категорий, аналитики промпта, истории, пресетов и интеграции с Groq API.

## Возможности

- Ввод базового текста и сборка структурированного промпта.
- Выбор стилей через удобные категории с поиском.
- Настройка качества: разрешение, освещение, цвета, фокус и детализация.
- Выбор художественных категорий с счётчиками и сворачиваемыми группами.
- Аналитика промпта: количество токенов, уровень сложности и рекомендации.
- Визуальный предпросмотр структуры собранного промпта.
- AI-улучшение промпта через Groq API.
- Переключение темы со светлым и тёмным режимом.
- История ранее созданных промптов.
- Сохранение, загрузка, экспорт и импорт пресетов.
- Окна перевода и обратного перевода.
- Окно справки с подсказками по API.
- Адаптация интерфейса под мобильные устройства.

## Как это работает

Приложение собирает промпт из нескольких слоёв:

1. Исходный текст пользователя.
2. Выбранные стили.
3. Параметры качества.
4. Художественные уточнения.
5. Необязательное AI-улучшение через API.

Готовый результат отображается в поле вывода, а отдельная панель показывает улучшенную версию, полученную от API.

## Настройка

1. Откройте HTML-файл в браузере.
2. Введите Groq API key в соответствующее поле.
3. При необходимости укажите имя модели.
4. При желании включите сохранение ключа локально.
5. Используйте интерфейс для создания и улучшения промптов.

## Сохраняемые данные

Приложение использует localStorage для хранения:

- предпочтений темы;
- API-ключа, если включено сохранение;
- имени выбранной модели;
- истории промптов;
- сохранённых пресетов.

## Структура интерфейса

### Основные панели
- Панель ввода исходного промпта.
- Панель вывода собранного промпта.
- Панель AI-улучшения результата.

### Секции управления
- Styles.
- Quality.
- Artistic categories.
- History.
- Presets.

### Вспомогательные окна
- Окно справки.
- Окно перевода.
- Диалоги сохранения и импорта пресетов.
- Уведомления и toast-сообщения.

## Работа на мобильных устройствах

Интерфейс адаптирован для небольших экранов за счёт:

- увеличенных зон нажатия;
- более удобных отступов;
- адаптивного расположения панелей;
- улучшенного поведения сворачиваемых секций;
- переноса и корректировки фиксированных кнопок.

## Интеграция с API

Функция улучшения использует Groq API для преобразования текущего промпта в зависимости от выбранного режима. Поддерживаются режимы:

- Artistic.
- Technical.
- Cinematic.
- Anime.
- Minimalist.

## Рекомендуемый сценарий работы

- Введите черновой промпт.
- Уточните его с помощью стилей и параметров качества.
- Добавьте художественные категории при необходимости.
- Проверьте аналитику и предпросмотр.
- Используйте улучшение, чтобы получить более сильный итоговый вариант.
- Сохраняйте удачные промпты в виде пресетов для повторного использования.
